# RAUF BAHERUNI — Glass Converter

Professional GitHub Pages-ready static photo converter.

## Upload only these 3 files to the repository root
- `index.html`
- `README.md`
- `rauf-baheruni.jpg`

**No assets folder is required.**

### GitHub Pages
Create a Public repository → upload the three files → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

Features include photo/camera upload, premium responsive UI, 3024×4032 JPEG export, framing/zoom controls, interactive perspective spin, auto-spin and 1080×1920 WebM Story export.

This is an independent photo utility and does not reproduce proprietary Meta/Ray-Ban algorithms. Not affiliated with Meta, Ray-Ban or Instagram.
